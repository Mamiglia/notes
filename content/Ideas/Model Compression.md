Can we observe the behavior of LLMs in narrow-tasks to extract a compressed version of this model that can achieve the same amount of accuracy as the original model?

This is somewhat similar to distillation, but I posit that training is not actually needed. I believe that we could observe the pattern of latent activations of a model and prune all the subspaces that the model is not using via SVD.
